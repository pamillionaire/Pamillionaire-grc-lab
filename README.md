# Pamillionaire GRC Lab

#### Cybersecurity home lab built by Paolo.



##### Objectives

* Build a SOC environment using Splunk
* Deploy Active Directory
* Collect and analyze Windows logs
* Implement Sysmon monitoring
* Map detections to MITRE ATT\&CK
* Apply NIST CSF 2.0 and CIS Controls
* Practice Incident Response
* Explore AI Governance concepts

* Splunk Enterprise
